# 매체 이용 허락 문의 메일 초안

이용약관상 상업적 이용에 허락이 필요한 매체(docs/rss-terms.md 의 A 분류)에 보낼 문의 메일입니다. 발송 전에 보내는 사람 이름과 연락처를 확인하세요. 매체별 담당 부서나 메일 주소는 docs/rss-terms.md 의 문의처와 각 매체 RSS 안내 페이지를 참고합니다.

## 우선순위

1. RSS 안내 페이지에서 상업적 이용을 직접 막은 곳: 연합뉴스, 아시아경제, 노컷뉴스, 동아일보, 비즈워치, 경향신문
2. 한국언론진흥재단(KPF) 경로가 있는 곳: 한겨레, 경향신문, 서울신문, 헤럴드경제. KPF 에 여러 매체를 한 번에 처리할 수 있는지 함께 문의합니다.
3. 나머지 A 매체: 이데일리, 블록미디어, 바이오스펙테이터, 산업일보, 매일경제, 이코노미스트, 이코노미조선, 전자신문, 지디넷코리아, 아웃스탠딩, 게임메카, 한국경제
