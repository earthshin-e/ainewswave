# 디자인 참고: CNET Tech

참고 주소: https://www.cnet.com/tech/ (2026-10-06 확인)

`/impeccable` 점검과 다음 디자인 작업에서 기준으로 삼을 특징입니다.

- 첫 화면은 검은 띠 위에 굵은 흰 헤드라인(36px, 700)과 짧은 소개 문장. 그 아래 섹션 이동 버튼이 외곽선 박스로 줄지어 있음.
- 로고는 빨간 세리프 워드마크 하나가 브랜드를 다 짊어짐. 나머지 UI 는 흑백.
- 글꼴은 그로테스크 계열(Monument Grotesk) 하나. 본문 15px, 카드 제목 15px 700 으로 작고 굵게.
- 섹션 제목은 대문자 레이블(TECH, MOBILE, LATEST STORIES)로 끊고, 섹션마다 대표 기사 1건을 크게, 나머지는 작은 목록.
- 포인트 색은 연보라 `#d5baff` 를 검은 바탕 위 링크와 버튼 테두리에만 씀. 흰 바탕 영역은 거의 무채색.
- 장식(그라데이션, 둥근 카드, 그림자, 아이콘 점) 대신 굵기와 크기 대비, 굵은 구분선으로 위계를 만듦.
